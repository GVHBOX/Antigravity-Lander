# Antigravity 中文补丁守护

配套 **antigravity-ide-zh** 使用的辅助扩展。它不做翻译本身，只负责让翻译补丁在 IDE 自动更新后不丢失。

## 它解决什么问题

Antigravity IDE 的自研界面（智能体面板、快捷设置弹层、设置窗口）不走 VS Code 的 `localize()`，官方语言包覆盖不到，只能把词表追加进窗口入口脚本。而 IDE 一旦自动更新，这些文件会被新版本覆盖，中文界面就退回英文。

本扩展在每次启动完成后检查一次：补丁还在就什么都不做；被冲掉了就重新写入并同步 `product.json.checksums`（否则 IDE 会弹「安装似乎损坏」）。

## 行为

| 情况 | 结果 |
| :--- | :--- |
| 补丁完好 | 零写入、零提示、立即返回 |
| 补丁被更新冲掉 | 重新写入入口脚本 + 刷新校验和，提示一次 |
| 找不到入口脚本 | 跳过并记录日志，不影响 IDE 启动 |
| 结构对不上（官方改了文件布局） | 拒绝写入，避免把编辑器改坏 |

写入前先比对文件头部若干字节未变、写入后确认内容一致；原始文件保留为 `*.orig-nozh`。

它**不是常驻进程**：激活时执行一次检查就结束，不占后台、不占端口、不开机自启。

## 关闭与卸载

- 临时停用：在本扩展目录下新建一个名为 `disabled` 的空文件，重启 IDE 后不再自愈（已打好的补丁保留）。
- 卸载：删除本扩展目录，或运行主项目的 `npm run restore`（会同时还原入口脚本与 `product.json`）。
- 注意：**把扩展目录改名并不能停用**，VS Code 按 `package.json` 加载扩展，不看目录名。

## 与主项目的关系

本目录是 [antigravity-ide-zh](../README.md) 的一部分，由 `npm run guard` 安装到 `~/.antigravity-ide/extensions/`。请从主项目更新它，不要单独修改已安装的副本。
